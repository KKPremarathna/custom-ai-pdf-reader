# Custom AI PDF Reader

A custom desktop PDF reader being built step by step with Python.

## Current progress

- Opened and inspected local PDF documents with PyMuPDF
- Rendered PDF pages as images
- Implemented page navigation
- Added zoom controls
- Added direct page navigation
- Added document text search
- Added visible highlights for matching text

## Planned features

- Desktop application interface with PySide6
- Bookmarks and notes
- PDF annotations
- Local LLM-powered paper summaries and Q&A
- Text-to-speech reading
- Voice commands
- Installable Linux desktop application

## Technology

- Python
- JupyterLab
- PyMuPDF
- Pillow
- ipywidgets
